# CorollaryHub

Syncs distributed databases for small to medium-sized businesses with multiple site locations.

With CorollaryHub, you get a lightweight tool that stays out of your way.

**What you get**

- Syncs distributed databases for small
- to medium-sized businesses with multiple
- site locations

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/CorollaryHub.git`
2. `cd CorollaryHub`
3. Install in editable mode: `pip install -e .`

## Configuration

CorollaryHub is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
